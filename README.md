# Motor LUMO
Motor pedagógico inteligente basado en FSM (Máquina de Estados) para la personalización del aprendizaje en el nivel educativo básico mexicano.

## Estructura del Proyecto
- `/core`: Lógica central (FSM, gestión de sesiones, orquestador y control de dificultad).
- `/logic`: Motor pedagógico y API de generación de contenidos.
- `/interface`: Interfaz de usuario construida con Streamlit.
- `/utils`: Herramientas de soporte (logger, seguridad, fechas).

## Tecnologías
- Python 3.9+
- Streamlit
- Google Gemini API
